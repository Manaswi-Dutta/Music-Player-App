# Music Player App

A **responsive music player** built using **HTML, CSS, and JavaScript**.  
This app allows users to play, pause, and switch between songs with an elegant UI and smooth animations.

---

##  Features
-  Play, pause, and skip songs  
-  Displays song title, artist, and album image  
-  Shows song duration and progress bar  
-  Auto-next functionality when a song ends  
-  Fully responsive design for all screen sizes

---

##  Tech Stack
- **HTML5** – Structure of the app  
- **CSS3** – Styling and responsive layout  
- **JavaScript (ES6+)** – Music player logic and interactivity
